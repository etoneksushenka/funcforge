## Описание проекта

**FuncForge** — это расширение для среды разработки Visual Studio Code, предназначенное для создания, настройки, автоматической проверки и повторного использования параметризованных шаблонов арифметических функций на языке C++.

Плагин позволяет разработчику не писать типовые математические функции вручную, а конструировать собственные шаблоны, тестировать их на произвольных входных значениях с помощью встроенного вычислительного ядра и автоматически генерировать готовый код C++ с последующей вставкой в редактор.

## Основные возможности

1. **Менеджер шаблонов (CRUD):**
   - Включает 5 предустановленных шаблонов (сумма, разность, произведение, деление, сумма квадратов двух чисел).
   - Позволяет создавать собственные шаблоны, редактировать существующие, удалять их и сбрасывать список к начальному состоянию.
   - Сохраняет все пользовательские шаблоны между перезапусками VS Code через хранилище `ExtensionContext.globalState`.
2. **Гибкая параметризация:**
   - Выбор типа возвращаемого значения и параметров: `int`, `float`, `double`.
   - Произвольный список параметров (например, `a, b, c`).
   - Поддержка произвольных арифметических выражений в `return` с учётом приоритетов операций (`+`, `-`, `*`, `/`), унарного минуса и круглых скобок.
3. **Встроенный парсер и тестирование функций:**
   - Собственная реализация лексера и алгоритма сортировочной станции Дейкстры (Shunting Yard) для перевода инфиксных выражений в Обратную польскую запись (ОПЗ / RPN) без использования `eval()` и `new Function()`.
   - Вычисление контрольного значения функции перед генерацией кода.
   - Поддержка правил целочисленного деления C++ для типа `int` (отбрасывание дробной части к нулю).
4. **Многоуровневая валидация:**
   - Проверка синтаксической корректности имени функции и параметров по правилам C++.
   - Защита от использования зарезервированных ключевых слов C++ (`return`, `int`, `class`, `double` и др.).
   - Контроль уникальности параметров и проверка того, что в выражении используются только объявленные параметры шаблона.
   - Перехват деления на ноль и синтаксических ошибок в формуле.
5. **Интеграция с редактором VS Code:**
   - Копирование сгенерированного C++ кода в буфер обмена.
   - Умная вставка кода в текущий открытый файл (даже при потере фокуса из-за окна Webview) или автоматическое создание нового C++ документа.

## Запуск и использование

1. Откройте палитру команд VS Code (`Ctrl+Shift+P`).
2. Выберите команду **`FuncForge: Открыть менеджер шаблонов C++`**.
3. Выберите готовый шаблон или создайте собственный, укажите имя функции, введите тестовые значения параметров и нажмите **«Проверить и сгенерировать C++ код»**.
